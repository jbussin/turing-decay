The model

The human advantage over chance, A, is set by three factors. Within an architecture family f it decays as generator capability C rises. Deployment effort D pushes it down, below zero if the prompting is good enough. Hands-on expertise E is the only factor that pushes back.

A = A0,f · e−λf(C − C0,f) − δ·D + γ·E

Three factors in text

1 · Generator capability

Same release date, bigger model, lower accuracy

GPT-3 news articles, eight sizes released together (Brown et al., 2020). Accuracy falls 6.5 points per tenfold increase in parameters (r = −0.87), reaching chance at about 175B. Time is held constant, so capability is doing the work.

2 · Deployment effort

How the model is prompted can outweigh which model it is

Three-party Turing test, 5-minute chats (Jones & Bergen, 2025). Accuracy is the share of games where the interrogator picked the real human. Below 50%, the AI was picked as human more often than the human was.

3 · Observer expertise

Heavy users catch what novices miss

Articles from GPT-4o, Claude 3.5 Sonnet and o1-pro (Russell et al., 2025). Based on 4 novices and 5 experts, so treat the size of the gap as provisional.

Preregistered predictions

No audio or video accuracy data had been coded when these were written. Each applies to audio and video separately, and each names the result that would refute it.

  1. Generator decay. Within a lineage, newer generators yield lower accuracy.Refuted if the release-date slope is zero or positive in both modalities.
  2. Sawtooth reset. The first generator of a new architecture family is more detectable than the old lineage's trend predicts.Refuted if the reset term is zero or negative.
  3. No background observer clock. For a fixed generator, untrained accuracy does not rise with the year a study was run.Refuted if that slope is reliably above +2 points per year.
  4. Expertise. Heavy users of voice-cloning or video-generation tools detect better than untrained participants.Refuted if the difference is zero or negative.
  5. Deployment effort. Curated or post-processed stimuli (phone-codec audio, compressed social video) are harder to catch than raw outputs of the same generator.Refuted if the difference is zero or positive.
  6. Modality ordering. Video decays more slowly than audio.Refuted if video's slope is steeper than audio's.

Point predictions, recorded for scoring: audio stays above chance for the newest generators studied, and video decays at under half the per-year rate of GAN faces.

Code & data

Everything behind the figures is in this repository. The analysis is a random-effects meta-regression (DerSimonian-Laird, Knapp-Hartung) in plain NumPy and SciPy.

data/faces_pilot.csv        50 face experiments, coded
data/text_pilot.csv         17 text results from 9 studies
data/gpt3_size_ladder.csv   Brown et al. 2020, Table 3.11
analysis/faces_pilot.py     two-clock models for faces
analysis/text_pilot.py      text models and size ladder
preregistration.md          hypotheses, coding scheme, analysis plan

pip install -r requirements.txt
python analysis/faces_pilot.py
python analysis/text_pilot.py

Limitations: the face slope rests on about six generators; text variances are approximated from reported percentages; all coding was done by one author. See the preregistration for the full list.
